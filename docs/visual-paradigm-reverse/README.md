# Visual Paradigm Reverse (Class Diagram)

## Source folder
Use this folder when reverse:

`docs/visual-paradigm-reverse/src/main/java`

## Steps in Visual Paradigm
1. Open your project in Visual Paradigm.
2. Go to `Tools` -> `Code` -> `Instant Reverse...` (or `Code Engineering` -> `Instant Reverse...`).
3. Language: `Java`.
4. Add source path: `D:\Zalo_Faker\docs\visual-paradigm-reverse\src\main\java`.
5. Select package `com.zalofaker.model`.
6. Choose `Class Diagram` as target diagram (create new diagram).
7. Finish.

## Notes
- If diagram is crowded, use `Layout` -> `Auto Layout`.
- You can delete less important classes (for example `ReadReceipt`, `AIChatMessage`) to keep the diagram clean.
